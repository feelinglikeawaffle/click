# PIXELWILD — The World Beneath

A standalone pixel-art incremental game. Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Play
- Click the living world or **GATHER ESSENCE** to collect life essence.
- Buy upgrades in **GROW** and **BUILD** to create passive production.
- Discover creatures as your lifetime harvest grows; each creature adds passive essence.
- Use **PULSE** for a burst of essence, and **EXPLORE** for a small expedition.
- Awaken the world as you reach each lifetime essence milestone.
- At 1,000,000 lifetime essence, the Journal unlocks **WORLD FOLD**. Rebirth resets the current world but grants permanent resonance.

## Saves
Progress saves automatically in browser local storage. Use **JOURNAL → EXPORT SAVE** to download a backup. Offline earnings are calculated when you return (up to 8 hours).

## Publish with GitHub Pages
In the repository settings, open **Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub Pages will publish the game from `index.html`.

No build step or external game framework is required.
